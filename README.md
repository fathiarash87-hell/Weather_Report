# گزارش خودکار آب‌وهوا

یک اسکریپت پایتون که پیش‌بینی ۷ روزه‌ی آب‌وهوای چند شهر را از API رایگان Open-Meteo می‌گیرد و یک گزارش اکسل فرمت‌شده همراه با نمودار می‌سازد.

## امکانات

- دریافت پیش‌بینی ۷ روزه (دمای بیشینه، دمای کمینه و مجموع بارش) برای هر شهر
- ساخت فایل `weather.xlsx` با شیت جداگانه برای هر شهر (داده و نمودار خطی دمای بیشینه و کمینه)
- شیت **Summary** با خلاصه‌ی همه‌ی شهرها
- فرمت‌بندی هدر، تنظیم عرض ستون‌ها و ثابت‌کردن ردیف اول
- مدیریت خطای شبکه: اگر یک شهر جواب ندهد، بقیه‌ی شهرها ادامه پیدا می‌کنند

## نیازمندی‌ها

- Python 3.8 یا بالاتر
- اتصال به اینترنت
- کتابخانه‌ها:

```
pip install requests pandas openpyxl
```

## ساختار پروژه

```
Weather_Report/
├── Weather.py       اسکریپت اصلی
├── weather.xlsx     خروجی (بعد از اجرا ساخته می‌شود)
└── README.md
```

## نحوه اجرا

```
python Weather.py
```

بعد از اجرا، فایل `weather.xlsx` کنار اسکریپت ساخته می‌شود و شیت‌های `Tehran`، `Shiraz`، `Isfahan` و `Summary` را دارد.

## افزودن شهر جدید

در دیکشنری `cities` داخل اسکریپت، اسم شهر و مختصاتش (عرض و طول جغرافیایی) را اضافه کنید:

```python
cities = {
    "Tehran": (35.69, 51.39),
    "Shiraz": (29.59, 52.58),
    "Isfahan": (32.65, 51.67),
    "Tabriz": (38.08, 46.29),
}
```

## منبع داده

داده‌ها از [Open-Meteo](https://open-meteo.com) گرفته می‌شود. این API رایگان است و کلید نمی‌خواهد.

## نکته

اگر هنگام اجرا خطای `PermissionError` دیدید، فایل `weather.xlsx` را در اکسل ببندید و دوباره اجرا کنید.
